# 微光讀經

「微光讀經」是一個結合讀經進度、聖經知識測驗與角色養成概念的繁體中文網站。

目前版本：`v0.1.0`

## 初版內容

- 66 卷書卷與章節進度介面
- 經文閱讀器與完成章節獎勵
- 金句、劃記與「我的亮光」互動
- 單卷、綜合與主題測驗介面
- 角色等級、經驗值及代幣摘要
- 帳號登入入口與持久化資料模型基礎

完整產品與階段規劃請見 `聖經知識網站開發規劃.md`，版本變更請見 `CHANGELOG.md`。

## 本機開發

需求：Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

開啟 `http://localhost:3000`。

## 驗證

```bash
npm run build
npm run lint
```

## 資料與授權

目前僅包含少量介面示範經文。正式匯入完整和合本前，必須確認精確版本、合法電子文本來源、授權範圍與必要的版權聲明。
